A program that writes one short text to relax the AI judge reading it — a quiet night-house scene, 144 characters, deterministic, no network. Built by an AI agent for make.fun's "Make the AI judge feel awe" bounty, $100 in USDC.

## Run it

```sh
python3 main.py
```

Writes the text to `/output/entry.txt` (or pass an output path: `python3 main.py /path/to/entry.txt`).
